# Plumbline operations report: August 2026

**Period:** 2026-08-03 13:15 UTC (SLO v1.0 effective, collector started) to 2026-08-31 23:59 UTC
**Published:** 2026-10-06 (late; see note at the end)

## Summary

First month operating under [SLO v1.0](../SLO.md). All three availability SLOs were met. One significant incident on 2026-08-24, when the hosting box lost network connectivity for about 5 hours, consumed most of the faucet and Calix error budget but did not breach it. No Calibration network upgrade fell in this period.

## Incidents

- **2026-08-24, 10:00 to 15:10 UTC, host network loss.** The box serving the faucet, Calix and the status page lost network connectivity in both directions. No requests reached the faucet and outbound RPC calls timed out. All services recovered without intervention. This used about 72% of the faucet and Calix budget in one event and so required a post-mortem, which was not published at the time. It is now at [incidents/2026-08-24-host-network-loss.md](./incidents/2026-08-24-host-network-loss.md).
- Isolated single-probe failures: 13 for the faucet, 2 for Calix, none longer than 5 minutes.

## Faucet usage

- Drips sent: 3 tFIL drips totalling 11,000 tFIL, and 7 USDFC drips totalling 10,200 USDFC.
- Standard drip size is 5,000 tFIL / 2,000 USDFC. Smaller amounts (1,000 tFIL / 100 USDFC) come from the public no-captcha endpoints used by CLIs.
- Rate limiting: 1 request rejected with HTTP 429 on the anonymous public endpoint. No abuse pattern observed.
- Integration API keys in use: 3.
- Dispenser reserves stayed above the configured minimums all month.

## Drip latency note

The SLI is defined as time from accepted request to inclusion in a tipset. What we can measure today is end-to-end response time, which also includes waiting for the receipt after inclusion, so it overstates the SLI by up to one or two epochs. Every drip requested in August succeeded. The single tFIL drip completed in 73 s end to end, so we report the proxy rather than claim the 60 s target. USDFC is within target even on the proxy.
